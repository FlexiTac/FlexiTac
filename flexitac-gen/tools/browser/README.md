# Browser checks (Playwright)

End-to-end checks of the browser UI in `web/`, archived from the stage-F work
of the 2026-10-13/14 audit fix.  They drive headless Chromium against a
running `app.py`, so they need Playwright and are **not** part of the stdlib
unittest suite (`unittest discover -s tests` never collects `tools/`).

Run them from a virtual environment of your own (outside the project):

```bash
python3 -m venv /tmp/fpc-browser-venv
/tmp/fpc-browser-venv/bin/pip install playwright pillow
/tmp/fpc-browser-venv/bin/playwright install chromium

python3 -B app.py --port 18801 &                    # from the project directory; -B: no bytecode
FPC_PORT=18801 /tmp/fpc-browser-venv/bin/python tools/browser/orient.py
FPC_PORT=18801 /tmp/fpc-browser-venv/bin/python tools/browser/ui_checks.py [part_name ...]
FPC_PORT=18801 /tmp/fpc-browser-venv/bin/python tools/browser/mutants.py [name fragment ...]
FPC_PORT=18801 /tmp/fpc-browser-venv/bin/python tools/browser/cad_checks.py [part_name ...]
FPC_BORDER_PORT=18801 /tmp/fpc-browser-venv/bin/python tools/browser/border_checks.py --external [--only model|ui]
```

The interface folds what goes beyond the basic flow (Advanced, More options, the design checks, the notes) and
hides the rectangular form in CAD mode: every script opens its pages with every fold open, the form shown and the
results in sight (`rp.unfold`), so its checks reach each control; `ui_checks.py part_clean_interface` and
`cad_checks.py part_clean_cad` check the folded default (the basic controls in sight, the rest folded, the design
checks one line that opens on a failure with only the failing rules, CAD mode's results after its own Generate, and
the Top and Bottom FPC Gerber ZIPs first among the downloads, filled and bold).

Each script prints one `PASS`/`FAIL` line per check and a summary, and
exits non-zero when a check fails.  Screenshots and downloads go to
`$FPC_BROWSER_OUT` (default: `fpc-browser-checks` in the system temp
directory), never into the project.
